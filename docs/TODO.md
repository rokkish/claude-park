## 実測で分かったこと（要判断）

1 の実測で、SPEC §7 の検算表が前提にしていた数値のうち**水平到達が実際より短い**ことが
分かりました。高さは解析値の方が高い（安全側）ので、高さで「届かない」としている箇所は
そのまま成り立ちます。

| | SPEC の値 | 実測 |
| --- | --- | --- |
| 単独の高さ | 62.5px | 58px |
| ブーストの高さ | 86.5px | 82px |
| 箱＋ブーストの高さ | 110.5px | 106px |
| 二段ジャンプの高さ | 149px | 140px |
| 単独の隙間 | 約87px | **106px**（4タイル=96px を越えられる） |
| 2人での隙間 | 約102px | **ブースト 139px / 二段 206px**（5タイル / 8タイルまで） |

2人での隙間が伸びるのは、上の人が土台の頭に乗ったまま運ばれ、その間ずっと接地扱いで
跳べるためです（土台が跳んだ弧の終わりで跳ぶと、弧2本ぶん進む）。土台は隙間に落ちます。

これで前提が崩れる既存ステージ（`npx vite-node scripts/check-stage.ts <ラベル>` で再現）:

- **1-3 Bridge**: 谷 144px を二段ジャンプで1人が越えられる（実機の入力で確認済み）。
  SPEC は「跳躍不能」。越えた先に板があるので、橋を使わない手順が成立し得る。
- **1-4 Two Keys**: 渓谷 120px をブーストで1人が越えられる（同上）。SPEC は「跳躍不能」。
- **4-1 Breakout / 4-3 Door の谷 144px**: SPEC は「二段ジャンプの水平到達 102px を超える」としているが、
  二段ジャンプで1人は越えられる。
- **4-2 Chimney の「橋の欠けが4タイル(96px)は跳べない」**: 単独で越えられる（踏み切りの猶予は5フレーム）。
- **深さ 120px の穴**: 2人とも落ちていれば、二段ジャンプ (140px) で1人は登り返せる。
  SPEC は「頭に乗っても 86.5px なので登り返し不能」。

いずれも「1人が渡れる／登れる」であって、2人ともゴールに着けるかは別です。想定外の手順で
クリアできるか・詰むかはステージごとに確認が要ります。直すなら谷を 9タイル以上にするか、
二段での水平移動そのもの（頭の上で運ばれている間のジャンプ）を物理側で見直すかです。
